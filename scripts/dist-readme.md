# OA CLI v2.4.0 - Windows Distribution

## Installation

1. Download `oa-cli-v2.4.0-windows.zip`
2. Extract the zip file
3. Place `oa-cli-v2.4.0-windows.exe` in a directory in your PATH, or run it directly

## Usage

```bash
# Show help
oa-cli-v2.4.0-windows.exe --help

# Use the CLI (rename to 'oa.exe' for convenience)
oa-cli-v2.4.0-windows.exe [command]
```

## System Requirements

- Windows 10 or later
- No additional dependencies required (Node.js runtime included)

## File Information

- **Size**: ~86MB (includes full Node.js runtime)
- **Platform**: Windows x64
- **Version**: 2.4.0
